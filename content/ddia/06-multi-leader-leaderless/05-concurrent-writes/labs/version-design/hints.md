## Hint 1
Chaque écriture incrémente le numéro de version de la clé. Une écriture avec la version n écrase les valeurs ≤ n et garde les autres ; sans version, elle n'écrase rien.

## Hint 2
Pour comparer deux vecteurs, complète les entrées absentes par 0, puis regarde si l'un est partout ≥ l'autre.

## Hint 3
À l'étape 4, la valeur de version 3 (`[jazz, soul]`) n'a pas été vue par Chloé : elle reste. À l'étape 5, rien n'est écrasé.
