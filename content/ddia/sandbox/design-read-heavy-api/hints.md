## Hint 1
Commence par le chemin de la requête : navigateur → API gateway → service.

## Hint 2
Redis doit être en mode *cache* (panneau de droite) : c'est lui que le service interroge d'abord.

## Hint 3
Le réplica se relie à la base principale avec une flèche de nature *réplication* ; la file avec une flèche *asynchrone*.
