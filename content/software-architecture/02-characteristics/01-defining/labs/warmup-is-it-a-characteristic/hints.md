## Hint 1
Une exigence du domaine décrit ce que fait le système ; une caractéristique, un critère de succès qui façonne la structure.

## Hint 2
Si une bonne pratique standard suffit, sans module ni service dédié, c'est de l'hygiène.

## Hint 3
Opérationnelle : comment le système tourne. Structurelle : comment le code est bâti. Transverse : le reste (légal, accès, sécurité…).
