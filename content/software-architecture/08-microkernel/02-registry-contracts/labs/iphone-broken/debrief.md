**Deux règles enfreintes, deux symptômes.** Le plug-in Galaxy a importé (et modifié) une fonction du plug-in iPhone : changer l'un a cassé l'autre, d'où les prix aberrants. Le plug-in iPhone lisait directement la base centrale : la migration a cassé son rapport.

Les remèdes rétablissent l'indépendance : pas de code partagé entre plug-ins (ou une bibliothèque stable et versionnée hors des plug-ins), des données fournies par le cœur, et une **fitness function** qui rend ces deux règles vérifiables à chaque commit (archkit le fera dans le projet de ce module).
