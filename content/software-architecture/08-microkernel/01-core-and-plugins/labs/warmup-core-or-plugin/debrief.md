**Le cœur porte ce qui est commun, les plug-ins ce qui varie.** Enregistrer, trouver le plug-in, afficher le rapport : c'est le chemin nominal, identique pour tous les appareils. Tester une batterie, calculer une décote, vérifier un verrouillage : ce sont des spécificités, isolées chacune dans son plug-in.

Le mode de chargement suit le rythme de livraison : un produit livré deux fois par an se contente de plug-ins compilés ; une plateforme qui ajoute des modèles à chaud paie la complexité d'un chargement à l'exécution.
