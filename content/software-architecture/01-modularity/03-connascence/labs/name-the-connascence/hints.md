## Hint 1
Demande-toi sur quoi les deux côtés doivent s'accorder : un nom, un type, une signification, un ordre, un algorithme… ou un moment, des valeurs liées, une même instance.

## Hint 2
Les quatre formes dynamiques n'apparaissent qu'à l'exécution : ordre des appels, concurrence, valeurs qui doivent changer ensemble, instance partagée.

## Hint 3
Chaque refactoring fait descendre la connascence : position → nom (objet d'options), sens → nom (constante), exécution → type (constructeur complet).
